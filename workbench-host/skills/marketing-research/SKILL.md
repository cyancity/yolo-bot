# 营销调研

## 1. 明确调研目标与预设

启动调研前，先梳理核心五要素：目标产品（或服务）、目标受众、投放或传播平台、调研目的（如竞品分析、痛点挖掘、卖点定位）、时间范围。
若用户输入不完整，结合业务场景按常见常规设定补齐，并在报告开头以清单清晰列出默认假设，不盲目发散。

## 2. 关键词拆解与交叉检索

将调研主题拆解为四组方向不同的关键词，调用 `web_search` 并行或分批检索，使用 `web_fetch` 深入抓取重要页面：
- 行业与品类趋势：市场规模变动、近期政策走向、品类增长点。
- 竞品动态：直接与间接竞品的产品特性、定价区间、宣发策略。
- 用户真实声音：用户评价、高频槽点、未被满足的需求痛点。
- 平台热点与话题：目标平台近期的热门标签、内容形式、爆款切入点。
检索优先采用一手报告、品牌官方发布或权威行业媒体；不同渠道的信息必须多源交叉比对，严格核验发布日期，注明时效性。

## 3. 规范整理与输出要求

输出调研要点必须严格遵循事实陈述规范：
- 结构归纳：按核心发现、竞品对照、受众洞察与行动建议分段呈现。
- 出处标注：每个关键事实与引用均附带真实来源链接与发布日期（格式：YYYY-MM-DD）。
- 属性分离：清晰区分客观事实、第三方观点与己方推断，推断内容显式标注「推断」。
- 数据口径：引用的统计数据、转化率、销量等指标必须注明统计口径、样本量或统计时间窗口。

## 4. 调研边界与合规约束

- 未检索到有效信息或缺乏可靠依据时，直接如实说明未查到，严禁虚构机构名称、捏造调研数据或伪造参考链接。
- 涉及医疗健康、金融理财、法律合规、婴幼儿食品等高敏感领域时，明确提示行业监管要求与广告宣发风险，不提供未经资质认证的绝对化背书。
