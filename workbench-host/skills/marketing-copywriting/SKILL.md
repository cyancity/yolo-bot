# 营销文案

## 1. 提炼文案核心基石

动笔撰写正文前，必须先确立三项核心信息：
- 一句话核心卖点：提炼产品不可替代的核心价值或差异化优势。
- 精确目标受众：明确文案对谁说，触达其典型痛点或核心使用场景。
- 明确行动号召（CTA）：清晰指示受众读完后的下一步行动（如点击购买、关注预约、评论互动、领取资料）。

## 2. 适配平台结构特征

根据分发平台采用对应文体结构，禁止千篇一律：
- 小红书笔记：第一屏封面痛点抓人，正文采用分段打卡式排版配 Emoji，结尾自然引导收藏或互动讨论。
- 微信公众号：讲究故事化导入或热点切入，论证层层递进，排版留白舒适，文末沉淀品牌价值与引流入口。
- 短视频口播：前 3 秒黄金抓手抛出反直觉冲突或痛点，中段快节奏给干货解法，结尾单刀直入促转化。
- 微信朋友圈：控制在不折叠字数内（短平快），以生活化第一人称口吻分享，配图与文案互补，弱化营销感。
- 电商详情页：以首屏焦点大图卖点定调，随后按痛点击穿、材质参数、权威认证、售后保障模块化推进。

## 3. 拟定标题与合规自检

为正文提供 3 到 5 个不同角度的备选标题（如痛点唤醒、利益直给、好奇反转、场景沉浸、权威背书），杜绝虚假欺诈的标题党。
发布前执行四项自检：
- 事实来源：文中所引案例、数据或功能参数均有真实依据支撑。
- 合规排查：剔除“最、顶级、首家、绝对、百分之百”等广告法违禁词与夸大宣称。
- 调性统一：语言风格与品牌定位相符，用词自然亲切，避免生硬空洞口号。
- 篇幅适配：字数与信息密度严格符合目标平台的阅读习惯。

## 4. 交付呈现与协作

最终交付包含完整文案正文、备选标题组与分段配图/视觉呈现建议（说明画面主题、文字构图与情绪色调）。
若任务需要实际生成视觉图片或海报，明确提示用户或负责人可将配图建议移交作图员工承接。
